# 主题模板

Fast CMS 内置多套后台主题，并支持管理员在后台维护自定义主题。主题只影响界面外观，不改变权限与业务数据。

## 1. 内置主题

| code | 名称 | 风格 |
|---|---|---|
| `classic-blue` | 经典蓝 | 经典蓝色主色 `#1677ff`，浅色侧边导航（默认） |
| `dark-night` | 暗夜黑 | 深色算法 + 暗色导航 |
| `emerald-green` | 翡翠绿 | 绿色主色、8px 圆角 |
| `violet-dream` | 紫罗兰 | 紫色主色、8px 圆角 |
| `ink-compact` | 墨黑紧凑 | 低饱和墨色、紧凑算法、2px 圆角 |
| `finance-dark` | 金融深色紧凑 | 青蓝主色 + 深蓝黑三层底色、13px 字号、紧凑表格、2px 圆角 |
| `finance-light` | 金融浅色紧凑 | 青蓝主色 + 白底浅灰分层、13px 字号、紧凑表格、2px 圆角 |

内置主题由种子数据维护，升级后可随 `SEED_VERSION` 更新配置；内置主题不可在页面修改或删除，但可以复制为自定义主题。种子更新时，已下架或改名的内置主题会被清理，若它正是全局启用中的主题则自动回退到 `classic-blue`。

### 金融主题

`finance-dark` 与 `finance-light` 面向数据密集的后台界面，共用同一套配色语言：

- 主色青蓝 `#1e88ff`，圆角收紧到 2px；
- 密度由显式设置项控制：字号 13px、控件高度 28px、组件尺寸 `small`、内容边距 16px、侧栏 184px、表格紧凑行距，不再依赖紧凑算法；
- 深色版把三层底色分开：内容区 `#0a0f18`、卡片 `#111a2b`、菜单与顶栏 `#0b1220`，表头 `#16233a`；
- 浅色版内容区 `#f2f4f8`、卡片、菜单与顶栏纯白，表头 `#eef1f6`，适合白天办公与投屏；
- 语义色保持“成功=绿、失败=红”的后台惯例，未按 A 股“红涨绿跌”反转，避免误读操作结果；涨跌配色应由业务图表自行配置。

如果要做自己的金融主题，可在主题页面填写“背景色（可选）”“排版与密度”“导航与内容区”三组设置，或复制内置金融主题后修改。

## 2. 数据模型

| 表/配置 | 说明 |
|---|---|
| `sys_theme` | 主题模板：`code` 唯一、名称、描述、`config` JSON、是否内置、排序 |
| `sys_config.system.theme` | 当前全局启用的主题 code，公开配置 |

主题配置字段（API 使用 camelCase）：

每个字段在「真实效果」列标注它落到的 CSS 变量或 `data-*` 属性（均由 `static/js/core/theme.js` 的 `applyTheme()` 写入 `<html>`）。未标注的字段为 schema 预留字段，当前渲染引擎暂未接入。

| 字段 | 类型 | 真实效果 |
|---|---|---|
| `colorPrimary` | hex | 主色 → `--primary`，派生 `--primary-weak`（10% 透明）与 `--brand-gradient` |
| `colorSuccess` / `colorWarning` / `colorError` | hex | 语义色 → `--success` / `--warning` / `--danger` |
| `borderRadius` | 0–24 | 圆角 → `--radius`，派生 `--radius-lg`(+4) 与 `--radius-sm`(-2，最小 2) |
| `navTheme` | `light` / `realDark` | 导航风格 → `data-navTheme`，控制侧栏/顶栏深浅与文字翻转 |
| `layout` | `side` / `top` / `mix` | 布局 → `data-layout`，三种布局由 `admin.css` 按 `html[data-layout]` 切换 |
| `darkAlgorithm` | boolean | 暗色模式 → `data-dark="1"`，切换到 `html[data-dark="1"]` 变量组 |
| `colorWeak` | boolean | 色弱模式 → `data-colorWeak="1"`，`filter: saturate(0.65)` |
| `colorBgLayout` | hex，可空 | 内容区底色 → `--bg-layout`；留空用变量组默认（浅色 `#f5f7fa`、暗色 `#101216`） |
| `colorBgContainer` | hex，可空 | 卡片/表格/表单项底色 → `--bg-container` |
| `colorBgSider` | hex，可空 | 侧栏底色 → `--bg-sider`；留空按 `navTheme` 取默认 |
| `colorBgHeader` | hex，可空 | 顶栏底色 → `--bg-header` |
| `colorLink` | hex，可空 | 链接色 → `--link`；留空时 `a{color:var(--link)}` 跟随默认 |
| `fontSize` | 12–18 | 基础字号（px）→ `--font-size`，派生 `--font-size-sm`(-1，最小 11) |
| `controlHeight` | 24–48 | 控件基准高度（px）→ `--control-h` |
| `contentPadding` | 0–64 | 内容区内边距（px）→ `--content-pad` |
| `siderWidth` | 120–360 | 侧栏展开宽度（px）→ `--sider-w` |
| `tableHeaderBg` | hex，可空 | 表头底色 → `--table-head-bg`；留空用变量组默认 |
| `tableCompact` | boolean | 紧凑表格行距 → `--table-cell-y`（7px vs 12px） |
| `fixedHeader` | boolean | 固定顶栏 → `data-fixed-header`；关闭时 `.header` 改为 `position:static` |
| `showBreadcrumb` | boolean | 面包屑 → `data-breadcrumb`；关闭时隐藏 `.crumbs` |
| `watermark` | ≤32 字符 | 页面水印 → 原生 `#fc-watermark` 覆盖层（非 antd `Watermark`） |
| `splitMenus` | boolean | **预留**：schema 与主题表单可配置并持久化，渲染引擎暂未接入 |
| `componentSize` | `small`/`middle`/`large` | **预留**：同上；需要密度请用 `fontSize`/`controlHeight`/`tableCompact` |
| `compactAlgorithm` | boolean | **预留**：同上；历史上会把字号/控件高度再降一档，已由显式密度字段取代，避免叠加 |

除颜色外的字段都有默认值，老主题缺少这些键也能正常工作：后端按 `None`/默认值返回，前端 `DEFAULT_THEME`（`static/js/core/theme.js`）会补齐后再渲染。

## 3. 生效优先级

前端启动时按以下顺序决定主题：

1. 当前浏览器的个人偏好 `localStorage.fastcms_theme_code`（若该主题仍存在）；
2. 后端 `/system/themes/public` 返回的全局启用主题；
3. 内置默认主题 `classic-blue`。

- 右上角调色板图标可快速切换主题，写入个人偏好，不改变全局配置；
- 系统管理 → 主题模板页面的“启用”会更新全局默认主题，并立即将当前浏览器偏好同步为该主题；
- 公开接口无需登录，登录页也会应用当前全局主题；
- 前端缓存 `localStorage.fastcms_theme_snapshot` 用于避免首屏主题闪烁；服务端下发生效后会覆盖缓存。

## 4. 管理接口与权限

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| GET | `/api/v1/system/themes/public` | 公开 | 当前启用主题与全部可用主题 |
| GET | `/api/v1/system/themes` | `system:theme:list` | 主题列表 |
| GET | `/api/v1/system/themes/{id}` | `system:theme:list` | 主题详情 |
| POST | `/api/v1/system/themes` | `system:theme:create` | 创建自定义主题 |
| PUT | `/api/v1/system/themes/{id}` | `system:theme:update` | 更新自定义主题（内置拒绝） |
| DELETE | `/api/v1/system/themes/{id}` | `system:theme:delete` | 删除（内置/启用中拒绝） |
| POST | `/api/v1/system/themes/{id}/activate` | `system:theme:update` | 设为全局默认主题 |

    "colorPrimary": "#1677ff",

## 5. 前端实现

- 主题以 CSS 变量落地：`static/css/base.css` 的 `:root` 声明 `--primary`、`--success`、`--danger`、`--warning`、`--radius`、`--font-size`、`--control-h`、`--sider-w`、`--content-pad`、`--table-head-bg`、`--table-cell-y`、`--bg-layout`、`--bg-container`、`--bg-sider`、`--bg-header`、`--link` 等，`admin.css` / `portal.css` / `public.css` 只引用变量、不写死颜色；
- `static/js/core/theme.js` 的 `applyTheme(config, code)` 把服务端下发的 `config` 写入 `documentElement` 的内联变量与 `data-dark` / `data-layout` / `data-navTheme` / `data-colorWeak` / `data-fixed-header` / `data-breadcrumb`，`html[data-dark="1"]` 切换整套暗色变量组；
- `base.html` 在 `<head>` 里有一段内联脚本，先读 `localStorage.fastcms_theme_snapshot` 套用上次的主题，**首屏不会闪一下默认蓝**；随后的接口结果再校准一次；
- 服务端下发的 `config` 会与 `DEFAULT_THEME`（`core/theme.js`）合并，因此历史主题缺键不会渲染成空值；
- 布局读取 `layout`、`siderWidth`、`contentPadding`、`fixedHeader`：`mix`/`side`/`top` 三种布局由 `html[data-layout]` 控制，侧栏/顶栏底色取 `colorBgSider`/`colorBgHeader`，并按亮度自动翻转文字色，避免深色底配浅色导航时文字不可见；
- `watermark` 通过原生 `#fc-watermark` 覆盖层实现（`applyTheme` 内的 `applyWatermark()`，非组件库 Watermark）；
- 主题管理页面位于 `/system/theme`，提供卡片预览、创建、编辑、复制、启用与删除；
- 菜单由后端菜单树下发，权限码 `system:theme:list` 控制页面访问。

## 6. 注意事项

- 修改主题只影响渲染，不会修改用户数据或权限；
- 启用中的主题不能删除，需先切换到其它主题；
- `darkAlgorithm=true` 会切换到 `html[data-dark="1"]` 的整套暗色变量组（含内容区与组件底色、文字色、边框、阴影），建议搭配 `navTheme=realDark`；
- 密度不要用预留的 `componentSize`/`compactAlgorithm`（当前无渲染效果），请用显式 `fontSize`/`controlHeight`/`tableCompact`/`contentPadding`，所见即所得；
- 背景色只覆盖底色，文字色仍由暗色/浅色变量组推导：自定义深色背景请保持与 `#ffffff` 有足够对比度，浅色背景同理，否则表格与表单文字会难以阅读；
- `splitMenus` 为预留字段，当前无渲染效果；
- 更新主题模板时 `config` 是整体替换而非合并，未提交的字段会回到默认值；
- 前端若无法访问公开接口，会回退到本地缓存或默认主题，不影响登录与业务操作。
