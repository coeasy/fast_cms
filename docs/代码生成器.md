# 代码生成器

代码生成器针对**已存在的单表**生成一套可继续修改的 CRUD 骨架，支持在线预览、zip 下载与写入 `backend/generated/`。它不会自动建表、不会自动注册路由、不会覆盖已有文件。

## 1. 能力边界

支持：

- 单表、单列主键；
- 标量字段的列表、详情、创建、更新、删除；
- 生成 SQLAlchemy Model、Pydantic Schema、Service、Router、前端 ProTable 页面骨架、接入说明；
- 生成 `manifest.json`（文件清单 + SHA-256），便于核对与审计；
- 模块名、资源名、表名正则校验，防止路径穿越与非法标识符。

不支持：

- 多表关系、联合主键、复合外键；
- 自动编写/执行 Alembic 迁移；
- 自动修改 `main.py`、权限注册表、菜单或前端路由；
- 工作流、复杂联动、低代码页面；
- 覆盖已有文件。

系统表（`sys_`、`alembic_`、`sqlite_`、`_` 开头）会被拒绝生成。

## 2. 使用流程

### 页面

1. 打开 `/tool/codegen`（需要 `tool:codegen:list`）；
2. 选择可生成的表；抽屉打开时会拉一次 `GET /tool/codegen/tables/{table}/columns`，列出列名、类型、是否可空、主键/自增与默认值——生成器的模型与表单字段完全由这份列结构决定，单列主键是硬要求，系统表与复合主键表会在这里直接看出来；
3. 填写模块名（小写字母/数字/下划线，如 `crm`）、资源名（如 `customer`）与标题；
4. 预览生成文件；
5. 下载 zip，或写入生成目录（需要 `tool:codegen:generate`）。

### CLI

```bash
cd backend
# 仅列出将生成的文件路径
python -m app.cli gen --table crm_customer --module crm --resource customer --title "客户"

# 写入 backend/generated/<module>/<resource>/
python -m app.cli gen --table crm_customer --module crm --resource customer --title "客户" --write
```

生成目录必须位于 `backend/generated/` 下；目标目录已存在且非空时直接拒绝。

## 3. 生成内容

| 文件 | 内容 |
|---|---|
| `model.py` | 映射已有表的 SQLAlchemy Model |
| `schemas.py` | Create / Update / Out Pydantic 模型 |
| `service.py` | 基础 CRUD 与分页查询 |
| `router.py` | 受保护路由，声明 `{module}:{resource}:*` 权限码 |
| `frontend/page.html` | Jinja2 页面模板骨架：筛选表单 + 表格 + 新建/编辑弹窗 |
| `frontend/index.js` | 原生 ES Module 页面脚本：`DataTable` 取数、弹窗表单、增删改 |
| `README.md` | 接入步骤与注意事项 |
| `manifest.json` | 生成清单与每个文件的 SHA-256 |

生成的路由前缀为 `/{module}/{resource}`，权限码为：

```text
{module}:{resource}:list
{module}:{resource}:create
{module}:{resource}:update
{module}:{resource}:delete
```

## 4. 接入步骤

1. 将生成的 `model.py`、`schemas.py`、`service.py`、`router.py` 复制到 `backend/app/modules/<module>/`，保持包内相对导入；
2. 在 `backend/app/main.py` 中注册 router；
3. 在 `backend/app/bootstrap/permissions.py` 增加上述四个权限码；
4. 执行 `python -m app.cli sync-rbac`，再在角色页面给角色分配权限；
5. 将 `frontend/page.html` 复制到 `backend/app/web/templates/pages/<module>/<resource>.html`，`frontend/index.js` 复制到 `backend/app/web/static/js/pages/<module>/<resource>.js`；在 `backend/app/web/router.py` 的 `PAGES` 增加一条页面（`page` 取 `<module>/<resource>`），并在菜单管理或 `bootstrap/menus.py` 中注册菜单；页面脚本里的 `const API` 是**去掉前缀**的路径，由 `core.js` 的请求层补回，因此调整 `API_PREFIX` 不需要重新生成页面；
6. 重新执行 `make contract-check`（导出 OpenAPI、校验权限码、菜单路径与页面模板/脚本是否成对）；
7. 按业务补充数据范围、审计、字段校验与测试。

生成器映射的是已经存在的表，因此不需要为它生成迁移；若要创建新表，请单独编写 Alembic 迁移。

## 5. API

| 方法 | 路径 | 权限码 | 说明 |
|---|---|---|---|
| GET | `/api/v1/tool/codegen/tables` | `tool:codegen:list` | 表列表，含 `is_system`、`codegen_enabled`、列数 |
| GET | `/api/v1/tool/codegen/tables/{table}/columns` | `tool:codegen:list` | 列元数据 |
| POST | `/api/v1/tool/codegen/preview` | `tool:codegen:generate` | 返回文件路径与内容 |
| POST | `/api/v1/tool/codegen/download` | `tool:codegen:generate` | 返回 zip |
| POST | `/api/v1/tool/codegen/write` | `tool:codegen:generate` | 写入 `backend/generated/` |

请求体：

```json
{
  "table": "crm_customer",
  "module": "crm",
  "resource": "customer",
  "title": "客户"
}
```

- `module` 必填，`^[a-z][a-z0-9_]*$`；
- `resource` 可选，默认等于表名，规则同模块名；
- `title` 可选，默认等于表名。

写入成功返回实际写入的绝对路径列表；已存在目标或文件时返回 409，绝不覆盖。

## 6. 安全设计

- 只读取数据库表元数据，不执行用户输入 SQL；
- 表名/模块名/资源名必须匹配标识符正则；
- 生成文件路径解析后必须位于目标目录内，防止路径穿越；
- 写操作只允许在 `backend/generated/` 下；
- 目标目录非空或文件已存在时拒绝写入；
- 系统表、联合主键直接拒绝；
- 预览内容不包含数据库连接串、密钥等敏感信息。

## 7. 测试

```bash
cd backend
python -m pytest tests/unit/test_codegen.py
python -m pytest tests/integration/test_api.py -k codegen
```

单元测试覆盖：

- 生成的六个代码/说明文件与 `manifest.json`；
- Model 表名、Router 权限码、README 标题；
- 系统表拒绝、联合主键拒绝、非法标识符拒绝；
- manifest 哈希与文件内容一致；
- 生成的 Python 文件可通过 `compile()` 语法校验；
- 写入目标位于 `generated/` 之外时拒绝、目标目录非空时拒绝且不覆盖。

集成测试覆盖：

- 表列表与列元数据；
- 预览包含预期文件；
- 系统表预览返回 422。

目标的实际写入由单元测试在临时目录中验证；前端生成文件是纯原生 JS，接入后无需类型检查或构建，只需在 `PAGES` 里登记页面并刷新浏览器。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 表未出现在列表中 | 系统表或联合主键表不可生成；确认表名不以 `sys_` 开头 |
| 生成代码导入失败 | 按相对导入要求放入同一模块包，检查 `service.py` 的依赖 |
| 接口返回 403 | 新权限码尚未注册/未分配给角色，执行 `sync-rbac` 并授权 |
| 写入返回 409 | 目标目录已存在且非空，换资源名或人工合并 |
| 生成的前端没有菜单 | 生成器不写菜单与路由，请在菜单管理中录入 |
| 表结构变更后 | 重新生成到新资源名，或人工同步字段 |
